# Parallax command reference

Generated by `python -m live4d.parallax.scripts.gen_cli_reference`.
Live acquisition uses `python -m live4d --config pipeline.yaml`; see [the guide](GUIDE.md).

## `python -m live4d.parallax.offline`

| Parameter | Default | Description |
| --- | --- | --- |
| `--config` | `required` | Shared live4d YAML; parallax must be enabled. |
| `--source` | `required` | A .dstream recording or (..., H, W) .npy frames. |
| `--device` | `cpu` | PyTorch replay device; no Holoscan required. |
| `--source-rate` | `0` | Optional replay pacing in frames/s. |

## `python -m live4d.parallax.tools.simulate_4dstem`

| Parameter | Default | Description |
| --- | --- | --- |
| `--out` | `required` | Output prefix, e.g. out/sim256: writes <prefix>.npy / .dstream, <prefix>.json (parameters), <prefix>.flags (run.py flags) and <prefix>_phase.npy (ground truth on the scan grid). |
| `--format` | `['npy', 'dstream']` | What to write: frames as .npy (memory-mapped), a .dstream capture (Stream2 framing, bslz4), or both. |
| `--scan` | `(256, 256)` | Scan grid (probe positions). |
| `--detector` | `(96, 96)` | Canonical detector shape (the layout may transpose it). |
| `--energy` | `300000.0` | Beam energy (eV). |
| `--semiangle` | `10.0` | Probe convergence semiangle (mrad). |
| `--angular-sampling` | `0.5` | Detector angular sampling (mrad/px). |
| `--scan-step` | `2.0` | Scan step (Å); rounded to the simulation grid, the effective step is reported and written to the flags. |
| `--defocus` | `-2000.0` | Target defocus C10 (Å), abTEM convention (negative = underfocus); also the actual one unless --defocus-schedule. |
| `--c12` | `0.0` | Target astigmatism C12 (Å). |
| `--phi12` | `0.0` | Astigmatism angle phi12 (degrees). |
| `--rotation` | `-15.0` | Scan/detector rotation (degrees). |
| `--detector-layout` | `rows,cols` | Write the frames transposed/mirrored like this detector layout (run.py --detector-layout): rows,cols \| rows,-cols \| -rows,cols \| -rows,-cols \| cols,rows \| cols,-rows \| -cols,rows \| -cols,-rows. |
| `--dose` | `2000.0` | Electron dose (e/Å²) for Poisson counts; 0 = noiseless expected counts (.npy only). |
| `--n-particles` | `None` | Particles in the phase object (default: ~30%% area coverage). |
| `--passes` | `1` | Scan the area this many times in one series (ids continue past the scan). |
| `--defocus-schedule` | `None` | The microscope's actual C10 (Å) on each pass; --defocus stays the target. Plain numbers (e.g. -2600, not -2.6e3). |
| `--c12-schedule` | `None` | The actual C12 (Å) on each pass (at --phi12); --c12 stays the target. |
| `--seed` | `0` | Random seed (object and shot noise). |
| `--device` | `auto` | Torch device for the simulation (auto: cuda, then mps, then cpu). |
| `--batch` | `256` | Probe positions per simulation batch (lower it for large probes). |

## `python -m live4d.parallax.tools.calibrate_parallax`

| Parameter | Default | Description |
| --- | --- | --- |
| `recording` | `required` | A recorded scan: .dstream (tools/record_stream.py) or a .npy of frames (..., H, W) in raster order. |
| `--scan` | `required` | Scan grid. |
| `--energy` | `required` | Beam energy (eV). |
| `--semiangle` | `required` | Probe convergence semiangle (mrad). |
| `--angular-sampling` | `required` | Detector angular sampling of the recorded mode (mrad/px); scales the measured C10 and C12. |
| `--scan-sampling` | `required` | Scan step (Å). |
| `--rotation-prior` | `None` | Report the twin solution whose rotation is nearest this (e.g. the rotation used live). Default: the twin with \|rotation\| <= 90°. |
| `--group` | `None` | Edge of the square groups of bright-field pixels whose vBF images are aligned (default: about 256 groups). |
| `--mean-every` | `8` | Average every K-th frame for the mean diffraction pattern. |
| `--lowpass` | `None` | Highest spatial frequency (1/Å) the shifts are measured from; pixels within lowpass / Δk of the disk edge are not fitted. Default: 15%% of the disk radius in 1/Å, at most the scan's Nyquist frequency. |
| `--tol` | `0.01` | Stop the shift iterations when no shift changes by more than this. |
| `--max-iterations` | `30` | At most this many shift iterations. |
| `--no-loss` | `True` | Skip the variance-loss check along C10, rotation and handedness. |
| `--no-refine` | `True` | Keep the shift fit's C10 in --defocus: skip the refinement on the lattice (the C10 that sharpens a particle's lattice rather than its support film). |
| `--refine-band` | `None` | Spatial frequencies (1/Å) where the refinement looks for lattice spots. Default: from the scan's Nyquist frequency to 0.95× the scan frequency (what only upsampling recovers); e.g. a band about a lattice's reflections. |
| `--refine-span` | `None` | The refinement searches C10 within ± this of the shift fit (Å). Default: half the fitted \|C10\|, at least 10 depths of field. |
| `--device` | `cpu` | Torch device for the cross-correlations, the loss and the refinement. |
| `--out` | `None` | Write <prefix>.flags (run.py flags), <prefix>.json (all results) and <prefix>.png (diagnostics, needs matplotlib). |

## `python scripts/compare_accumulate.py`

| Parameter | Default | Description |
| --- | --- | --- |
| `source` | `required` | A looped capture (tools/repeat_dstream.py, one series). |
| `--modes` | `['latest', 'all', 'reset', 'swap', 'swap β=0.5']` | Modes to compare. |
| `--fractions` | `[0.25, 0.5, 0.75, 1.0]` | Points in each pass at which to take the live images. |
| `--channel` | `phase_flipped` | Channel to compare and show. |
| `--batch-size` | `2048` | Frames per batch, as run.py. |
| `--device` | `auto` | Torch device (auto: cuda, then mps, then cpu). |
| `--out` | `None` | Montage PNG to write (needs matplotlib). |
| `--detector` | `None` | Detector geometry (default: config, 192x192; --binned preset: 96x96). Changing the detector changes the BF disk — set --angular-sampling to match the mode. |
| `--binned` | `False` | ARINA 2×2-binned preset: 96×96 detector (give --angular-sampling of the binned mode). |
| `--defocus` | `None` | Target defocus C10 (Å) the parallax shifts are built for (negative = underfocus). Required. |
| `--rotation` | `None` | Scan/detector rotation (degrees). Required. |
| `--c12` | `None` | Target astigmatism magnitude C12 (Å). Config default: 0. |
| `--phi12` | `None` | Target astigmatism angle phi12 (degrees). Config default: 0. |
| `--upsampling` | `None` | Output-grid upsampling (finer grid → finer shifts). Config default: 1. |
| `--energy` | `None` | Beam energy (eV; 300 kV = 300000). Required. |
| `--semiangle` | `None` | Probe convergence semiangle, the bright-field cutoff (mrad). Required. |
| `--angular-sampling` | `None` | Detector angular sampling (mrad/px, isotropic) of the mode actually running (binned or not). Required. |
| `--scan-sampling` | `None` | Scan step (Å, isotropic). Required. |
| `--center` | `None` | BF-disk center on the raw detector frames (px), py4DSTEM's Center_X Center_Y from get_probe_size. Default: the frame center (mapped through --detector-layout). (The disk's radius is not an input: it is --semiangle / --angular-sampling.) |
| `--scan` | `None` | Scan grid; must match what the microscope drives. Required. |
| `--flip-cols` | `False` | The detector's columns are reversed relative to the canonical layout (LiberTEM's detector_flip_cols). With --rotation this covers every transpose/flip: e.g. a transposed detector is --rotation +90 --flip-cols. Give --center as measured on the raw frames. Table in docs/GUIDE.md. |
| `--detector-layout` | `None` | What the raw frame's (axis 0, axis 1) hold relative to the canonical (rows, cols) layout: rows,cols \| rows,-cols \| -rows,cols \| -rows,-cols \| cols,rows \| cols,-rows \| -cols,rows \| -cols,-rows. E.g. 'cols,-rows' = transposed with the second axis reversed. Adds the matching rotation and column flip to --rotation, and maps the default disk center onto the raw frame. Exclusive with --flip-cols. |
| `--subtract-frame-mean` | `False` | Subtract each frame's mean over its bright-field pixels before it is added in (as the reference implementation does). This removes the amplitude contrast (mass-thickness, diffraction) over regions larger than about the probe, and the frame-to-frame changes in beam intensity. Default: off, the mean is kept. |
| `--no-phase-flip` | `True` | Don't add the phase-flipped (sign(sin chi(q))) channel. |
| `--no-dc-correct` | `True` | Don't remove each bright-field pixel's running scan mean (it removes the static bright-field pattern at the scan front and on upsampled grids). |
| `--normalize` | `False` | Divide by the per-pixel deposit count (tapered below 1%% of its peak), so a partial scan reads at full brightness. |
| `--coverage` | `False` | Add the per-pixel deposit count as a channel. |
| `--lowpass` | `None` | Butterworth low-pass cutoff (1/Å). |
| `--highpass` | `None` | Butterworth high-pass cutoff (1/Å). |
| `--butterworth-order` | `12` | Steepness of the Butterworth low/high-pass edges. |
| `--suppress-nyquist` | `auto` | Zero the Nyquist row/column of the output (auto: on when --upsampling > 1). |
| `--band-limit` | `False` | Clamp the low-pass at the parallax band limit 2*alpha/lambda. |
